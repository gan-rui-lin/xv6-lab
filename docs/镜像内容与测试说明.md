# xv6 测试镜像内容与使用说明

## 1. 镜像概述

### 1.1 镜像文件
- **文件名**: `sdcard-rv.img` (压缩版: `sdcard-rv.img.xz`)
- **文件系统**: EXT4 (无分区表)
- **大小**: 4096 MB (4GB)
- **架构**: RISC-V 64位

### 1.2 镜像用途
该镜像是2025年系统能力培养赛操作系统赛的官方测试镜像，包含：
- 预编译的测试程序
- BusyBox 工具集
- musl libc 和 glibc 两套运行时环境
- 12组测试套件

## 4. 测试脚本格式

所有测试脚本遵循统一格式：

```bash
#!/bin/sh
./busybox echo "#### OS COMP TEST GROUP START <测试组名> ####"

# 执行测试
cd ./<测试目录>
./run-all.sh  # 或直接运行测试程序

cd ..
./busybox echo "#### OS COMP TEST GROUP END <测试组名> ####"
```

**重要标记**：
- 开始标记: `#### OS COMP TEST GROUP START <name> ####`
- 结束标记: `#### OS COMP TEST GROUP END <name> ####`

评测系统通过这些标记识别测试组的开始和结束。

## 5. 运行环境要求

### 5.1 QEMU 启动命令

```bash
qemu-system-riscv64 \
  -machine virt \
  -kernel kernel-qemu \
  -m 128M \
  -nographic \
  -smp 1 \
  -bios default \
  -drive file=sdcard-rv.img,if=none,format=raw,id=x0 \
  -device virtio-blk-device,drive=x0,bus=virtio-mmio-bus.0 \
  -device virtio-net-device,netdev=net,bus=virtio-mmio-bus.1 \
  -netdev user,id=net
```

### 5.2 系统要求

OS 必须实现：
1. **EXT4 文件系统支持** - 读取镜像内容
2. **动态链接器支持** - 运行动态链接的程序
3. **必要的系统调用** - 至少支持 basic 测试中的系统调用
4. **进程管理** - fork, exec, wait 等
5. **文件系统操作** - open, read, write, close 等
6. **网络支持** (可选) - 用于 iperf/netperf 测试

## 6. 调用方式

### 6.1 直接调用测试脚本

```c
// 在 init 进程中
chdir("/musl/");  // 切换到 musl 目录

int pid = fork();
if (pid == 0) {
    // 子进程执行测试
    char *argv[] = {"sh", "/musl/basic_testcode.sh", 0};
    char *envp[] = {"PATH=/bin:/musl:/usr/bin", 0};
    execve("/musl/busybox", argv, envp);
    exit(-1);
} else {
    // 父进程等待
    int status;
    wait(&status);
}
```

### 6.2 使用 BusyBox 执行命令

```c
// 执行单个命令
char *argv[] = {"busybox", "ls", "-l", 0};
execve("/musl/busybox", argv, NULL);

// BusyBox 会根据 argv[0] 自动识别 applet
// 也可以通过符号链接方式：ln -s /musl/busybox /bin/ls
```

### 6.3 顺序执行所有测试

```c
void run_all_tests() {
    const char *tests[] = {
        "/musl/basic_testcode.sh",
        "/musl/busybox_testcode.sh",
        "/musl/lua_testcode.sh",
        // ... 其他测试
        NULL
    };

    for (int i = 0; tests[i]; i++) {
        int pid = fork();
        if (pid == 0) {
            char *argv[] = {"sh", (char*)tests[i], 0};
            char *envp[] = {"PATH=/bin:/musl:/usr/bin", 0};
            execve("/musl/busybox", argv, envp);
            exit(-1);
        } else {
            int status;
            waitpid(pid, &status, 0);
            printf("Test %s completed with status %d\n", tests[i], status);
        }
    }
}
```

## 7. 评分机制

- **评分依据**: 屏幕输出内容
- **评分方式**: 自动化评测系统解析输出
- **测试顺序**: 无关评分，可自由选择
- **测试执行**: 只能串行执行，不可并行
- **跳过测试**: 可以跳过，跳过的测试不计分
- **输出格式**: 必须包含测试组开始/结束标记

## 8. 常见问题

### 8.1 "applet not found" 错误

**原因**: 尝试执行的命令不是 BusyBox 的 applet

**解决方案**:
1. 检查命令是否在 BusyBox 支持列表中
2. 使用完整路径执行程序
3. 确保测试程序已正确编译并放入镜像

### 8.2 动态链接错误

**原因**: 找不到动态链接库或链接器

**解决方案**:
1. 确保 `/musl/lib/libc.so` 或 `/glibc/lib/libc.so.6` 存在
2. 设置正确的链接器路径
3. 在 execve 时提供正确的 PATH 环境变量

### 8.3 页面错误

**原因**: 内存管理问题（VMA 越界、权限错误等）

**解决方案**:
1. 检查 mmap/munmap/brk 系统调用实现
2. 验证页表权限设置
3. 确保 COW（写时复制）机制正确

## 9. 构建自定义镜像

如需自定义镜像内容：

```bash
# 1. 创建空镜像
dd if=/dev/zero of=custom.img count=4096 bs=1M
mkfs.ext4 custom.img

# 2. 挂载镜像
mkdir -p mnt
sudo mount custom.img mnt

# 3. 复制文件
sudo cp -r /path/to/files/* mnt/

# 4. 卸载
sudo umount mnt

# 5. 压缩（可选）
xz custom.img
```
